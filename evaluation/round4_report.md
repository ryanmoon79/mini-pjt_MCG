## 3. 결론 (사용자 확정, 2026-11-12)

1. **본 세트는 20/20입니다** (C 18/20, 수정 기준). C에서 실패한 9번(`create_agent`가 없다는 오탐)과 17번(E711을 bug로도 지적)이 통과했고, 추가 세트는 22번(정렬된 import 함정 diff)이 53행의 가정형 high bug 지적으로 실패해 1/2입니다 — 5번의 가정형 경로 오탐과 같은 유형입니다. 케이스마다 1회 실행이라 차이에는 실행 간 변동이 섞여 있습니다.
2. **오탐이 줄었습니다.** 평가셋 bug 지적 수 29 → 14, 근거-지적 일치율 0.364 → 0.667, C2 제거 7 → 2(본 세트). 커밋 재리뷰 4건에서 화면에 나간 bug·security 지적은 13 → 5건입니다. 줄어든 몫은 리뷰어 단계(프롬프트 규칙)에서 나오지 않은 것과 출력 검증(⑥ day06 264행, ⑦ day07 113행)이 지운 것이 섞여 있습니다.
3. **정밀도는 0.15 → 0.20(판단 필요 포함 0.23 → 0.40)이지만, round4 분모는 표본 5건입니다.** 지적 1건이 바뀌면 0.20씩 움직이므로 C(13건)보다 나아졌다고 단정하지 않고 "나아진 경향"으로만 읽습니다.
